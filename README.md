## Datasets

This project uses two publicly available datasets.

### 1. Online Shoppers Purchasing Intention Dataset
Source: UCI Machine Learning Repository

This dataset contains online shopping session information and is used to predict whether a browsing session results in a purchase.

### 2. E-commerce Customer Churn Dataset
Source: Kaggle

This dataset contains customer characteristics and behavioural information and is used to predict customer churn.

The original datasets are not redistributed in this repository. Please access them from their original public sources.
